# 复脊｜腰背恢复教育 App

这是根据项目内麦吉尔方法课程资料和 `麦吉尔虚拟手术_16周完整训练计划.md` 制作的纯前端中文应用。它先做安全筛查，再根据当前功能、活动耐受、延迟反应和目标推荐活动起点；刷新后可继续，不要求注册账号。

## 直接使用

- 双击 `复脊_腰痛康复教育App_单文件版.html`：无需服务器，核心功能离线可用。
- 或在项目根目录运行：

需要康复师后台与课件发布时，进入 `BackPainWeb` 执行：

```bash
node server.mjs
```

浏览器打开：

```text
http://127.0.0.1:5173/
```

康复师后台：

```text
http://127.0.0.1:5173/admin
```

线上部署地址：

```text
https://bobjennies.click/spine-rehab/
```

线上康复师后台位于 `/spine-rehab/admin`。页面使用单一访问码进入，不需要账号和密码；访问码通过服务端 `ADMIN_TOKEN` 环境变量配置，课件读取、上传、保存、发布和清空接口均在服务端验证访问码。静态资源、课件接口和上传媒体均支持此前缀。

后台不预设跟练动作。康复师自行填写动作名称，并从“屈曲不耐受、伸展不耐受、压缩不耐受”三个触发模式标签中选择一类（标签不是医学诊断），再上传“跟练视频、跟练动作拆解、注意要领”。后台将视频和图片保存到 `uploads/`，将课件状态保存到 `server-data/courseware.json`。草稿不对用户显示；点击“发布并对用户生效”后，用户端刷新或等待自动更新即可看到。

站点版支持 Service Worker 缓存，并可在浏览器支持时安装为 PWA。

重新生成单文件版：

```bash
node BackPainWeb/build-standalone.mjs
```

## 已实现

- 成年人边界、分级警讯筛查和真实术后限制硬拦截；中国大陆紧急路径标注 120。
- “虚拟手术”作为管理隐喻，不鼓励卧床，不暗示组织脆弱。
- 根据当前功能与目标从 5 个能力阶段中的任一阶段起步，而非强制第 1 周。
- 标准、减量、最低三套真实剂量；训练前、训练后和次日反馈会改写后续计划。
- 32 个动作的准备、步骤、呼吸、起始量、常见错误、自查、简化版和停止信号。
- 康复师课件后台：自定义跟练动作名称，选择三类触发模式之一，在大预览中所见即所得地编辑视频、图片拆解和注意要领，发布后对用户生效。“进入专注预览”会收起编辑区，在一屏内并排展示视频、图片和文字；可点击“返回编辑”或按 Esc 退出。
- 完整 16 周内容作为可查阅参考课程，不凭周数或答题积分解锁身体训练。
- 微任务、生活情景、无惩罚回访与行为徽章；漏练、减量、暂停都不会清零。
- 日常坐站、搬物、工作间歇、步行、睡眠与一般均衡饮食教育。
- 作者视频工具：本地文件或 URL/相对路径、实际预览、替换、移除、映射导入导出。
- 公共视频发布：构建时只嵌入动作 ID 与 URL，新用户首次打开即有视频，不携带作者健康记录。
- v2 数据迁移、损坏状态备份恢复、JSON 校验后确认导入、清除前确认。
- 键盘焦点、移动端布局、高对比文字和 `prefers-reduced-motion` 支持。

## 数据与限制

用户端的个人记录保存在当前浏览器 `localStorage`，本地视频保存在 IndexedDB；康复师课件则保存在运行本服务的电脑上。数据不会自动同步到其他设备，也没有用户账号或医疗系统集成。导出的状态 JSON 不包含本地视频二进制文件。视频接入细节见 `VIDEO_INTEGRATION.md`，内容来源与边界见 `SOURCES.md`。

这是教育与记录工具，不提供诊断、医学分期、个体处方或运动/术后许可。
